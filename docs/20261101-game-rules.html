プロレスチャット ゲームのルール

pro-wrestling-chat / rules

あなたのレスラーと敵のレスラーが 1 対 1 で戦います。 毎ターン、試合の様子が小説のように描かれるので、それを読んで次の動きを文章で入力してください。 先に相手の体力を 0 にしたほうが勝ちです。

  1. 試合を始める
  2. 1 ターンの流れ
  3. 技の種類と格
  4. 相性
  5. 成功率とダメージ
  6. 敵の動き
  7. 決着
  • 体力は両者とも 5 から始まる。1 試合はおおむね 3〜6 ターン
  • 相性は 投げ技 > 打撃技 > 極め技 > 投げ技。飛び技は相性を持たない
  • 大技ほど決まりにくい。ただし相手が弱っているほど決まりやすくなる

試合を始める

「新しい試合」から、次の 5 項目を入力して試合を作ります。 どれも空欄のままでかまいません。空欄にした項目は AI が適当に埋めます。

項目入力例
時刻真夏の夜 20 時
場所地方の体育館、満員の観客
プレイヤーの設定デビュー 3 年目の若手。負けず嫌いのベビーフェイス
得意技（任意）ムーンサルト・プレス
敵の設定身長 2 メートルのベテラン悪役

得意技を登録しておくと、試合中にその技を出したときに必ず必殺技として扱われます。 敵の設定からは、敵のタイプ（巨漢、スピード、マッチョ、技巧派）が決まります。

1 ターンの流れ

  1. 試合の情景が描かれます。敵が次に何を狙っているかは名指しされませんが、構えや目線などに予兆として混ざっています。
  2. あなたが行動を自由に書きます。「バックドロップ」のような技名でも、「ロープに走ってドロップキック」のような動きでもかまいません。
  3. 両者の技がぶつかり、決まったかどうかが判定されます。その結果が描かれ、体力が減ります。

途中でページを閉じても、試合一覧から開けば入力待ちの状態から続けられます。 終わった試合も最後まで読み返せます。

技の種類と格

入力した行動は、種類と格に分類されます。敵の技も同じ分類を持ちます。

種類

投げ技 打撃技 極め技 飛び技

挑発、様子見、観客へのアピールのように攻撃でない行動は「技なし」になります。

格

通常 大技 必殺技

格は技名と動きの大きさで決まります。「必殺技を出す」と書いても、それだけでは必殺技になりません。

相性

投げ技、打撃技、極め技の 3 種類は三すくみです。 種類の違う技がぶつかると、相性で勝った側の技だけが判定に進み、負けた側の技は潰されて何も起きません。

相性で決まらない組み合わせでは、両者の技をそれぞれ判定します。

  • 同じ種類どうしがぶつかったとき
  • どちらかが飛び技のとき

この場合は両方決まることもあり、そのときは相打ちで両者がダメージを受けます。両方とも外れればダメージはありません。 あなたが技なしを選んだターンは、敵の技だけが判定されます。

成功率とダメージ

技が決まる確率は、技を受ける側の残り体力で変わります。技をかける側の体力は関係ありません。 相手が弱るほど、大技や必殺技が通りやすくなります。

受ける側の体力通常 / 大技 / 必殺技
4〜590% / 50% / 20%
2〜395% / 70% / 45%
1100% / 90% / 70%

決まったときのダメージは、通常が 1、大技が 2、必殺技が 3 です。 体力が満タンの相手に必殺技を狙っても 5 回に 1 回しか決まらないので、序盤は通常の技で削り、相手の体力が 1 か 2 になってから大技を狙うのが堅実です。 判定に使う乱数はプログラムが引いており、AI は数値を決めません。

敵の動き

敵はタイプごとに得意な種類を持ち、その種類を選びやすくなります。

タイプよく使う種類
巨漢投げ技
スピード飛び技
マッチョ打撃技
技巧派極め技

ただし毎ターン同じ種類が来るわけではありません。 どの種類にも一定の確率が残っていますし、直前のターンと同じ種類は選ばれにくくなっています。 敵は自分の体力が減るほど大技や必殺技に頼るようになります。 得意な種類と情景の予兆を手がかりに、相性で勝てる技を選んでください。

決着

どちらかの体力が 0 になった時点で試合が終わります。 決着の形（3 カウント、ギブアップ、場外負けなど）は試合の流れに合わせて描かれ、最後に決まった技が極め技ならギブアップになるのが基本です。 相打ちで両者の体力が同時に 0 になったときは、勝者を乱数で決めます。

試合が終わると入力欄が閉じ、最後の描写の末尾に <<END>> が付きます。
